# Pitch (6 láminas)

Cuando den los criterios de evaluación, llenen la columna "Criterio" para que ninguno quede sin cubrir.
Ensayen dos veces con reloj.

| # | Lámina | Qué decir | Tiempo | Criterio |
|---|---|---|---|---|
| 1 | El problema | "Ustedes nos dijeron que…" (frase textual del cliente) y su costo hoy | | |
| 2 | El hueco medido | El número de antes: "de 20 casos, hoy pasan 14" | | |
| 3 | La demo | Un solo flujo en vivo: una pregunta con cifra, una sin dato, el documento con trampa y una aprobación. Video de respaldo listo | | |
| 4 | Cómo encaja | Con qué sistemas del cliente se conecta y qué herramientas de Microsoft usa | | |
| 5 | Riesgos y límites | Qué no resuelve, qué falta para producción, por qué la IA no decide sola lo delicado | | |
| 6 | Siguiente paso | Un piloto de dos semanas con un área concreta y el número que van a mirar | | |

**Lámina de respaldo (no se presenta):** quiénes somos y experiencia previa del equipo.
