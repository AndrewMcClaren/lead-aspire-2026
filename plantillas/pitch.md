# Pitch (7 láminas)

Cuando den los criterios de evaluación, llenen la columna "Criterio" para que ninguno quede sin cubrir.
Ensayen dos veces con reloj.

**Regla 80/20 (consejo, no regla del evento):** el 80 % del tiempo va al problema, el impacto y la demo; como
mucho el 20 % a cómo funciona por dentro (qué herramientas de Microsoft lo hacen posible). La duración del pitch
no se publicó: pregúntenla al llegar y usen la columna que corresponda. Bogotá anuncia rondas y una final: tengan
también la versión de 2 minutos.

La estructura sigue la de un caso de consultoría: diagnóstico con datos → opciones → presupuesto y retorno →
demo → plan de implementación y riesgos. La lámina 4 es **solo financiera** y no se salta nunca, aunque el caso
no hable de dinero: un comité siempre pregunta cuánto cuesta y cuándo se recupera.

| Lámina | 2 minutos | 3 minutos | 4 minutos | 5 minutos |
|---|---|---|---|---|
| 1. El problema | 0:15 | 0:20 | 0:25 | 0:35 |
| 2. El hueco medido | 0:10 | 0:15 | 0:20 | 0:25 |
| 3. La demo | 0:35 | 0:55 | 1:15 | 1:30 |
| 4. Presupuesto y retorno | 0:20 | 0:25 | 0:35 | 0:45 |
| 5. Cómo encaja (la parte técnica) | 0:10 | 0:20 | 0:30 | 0:35 |
| 6. Riesgos y límites | 0:10 | 0:20 | 0:20 | 0:25 |
| 7. Siguiente paso | 0:20 | 0:25 | 0:35 | 0:45 |

| # | Lámina | Qué decir | Tiempo | Criterio |
|---|---|---|---|---|
| 1 | El problema | "Ustedes nos dijeron que…" (frase textual del cliente) y su costo hoy | | |
| 2 | El hueco medido | El número de antes: "de 20 casos, hoy pasan 14" | | |
| 3 | La demo | Un solo flujo en vivo: una pregunta con cifra, una sin dato, el documento con trampa y una aprobación. Video de respaldo listo | | |

| 5 | Cómo encaja | Con qué sistemas del cliente se conecta y qué herramientas de Microsoft usa | | |
| 6 | Riesgos y límites | Qué no resuelve, qué falta para producción, por qué la IA no decide sola lo delicado | | |
| 7 | Siguiente paso | Un piloto de dos semanas con un área concreta y el número que van a mirar | | |

**Láminas de respaldo (no se presentan; se muestran si preguntan):**
- Quiénes somos y experiencia previa del equipo.
- "¿Cómo saben que es seguro?": la tabla resumida de `docs/SANS.md` (16 controles sí, 2 parciales, 2 no aplican),
  con la frase "nos guiamos por OWASP, NIST y SANS", y la ficha del sistema de `checklist_ia_responsable.md`.

**Frase opcional para la lámina 5:** "La seguridad no es el departamento del no: es lo que les permite usar IA en
procesos que hoy no se atreven a tocar."
